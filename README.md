#STUDENT GRADING SYSTEM
This project is a Python-based student grading system developed in three sections.  
Each section builds on the previous one by adding more features and using more advanced Python concepts.


#section A:SCALAR OBJECTS AND LOOPS
##WHAT THIS SECTION DOES
- Asks the user for the number of students
- Accepts each student’s name and one grade
- Validates that the grade is between 0 and 100
- Calculates the total and average grade of the class
- Displays the results

###KEY CONCEPTS USED
- Variables (`int`, `float`, `str`)
- `input()` and `print()`
- `for` loop
- `while` loop for validation
- Basic arithmetic operations

  
#Section b: LISTS AND TUPLES
##WHAT THIS SECTION DOES
- Stores multiple subjects (Math, English, Science) for each student
- Uses a list to store grades and a tuple to store student information
- Calculates each student’s average
- Finds the highest and lowest grade for each subject
- Displays a summary table of all students

###KEY CONCEPTS USED
- Lists
- Tuples
- Nested data structures (list of tuples)
- `sum()`, `max()`, `min()`
- `for` loops and `enumerate()`


##Section C: DICTIONARIES
##WHAT THIS SECTION DOES
- Uses a dictionary to store student records
- Student name is used as the key
- Grades are stored in a nested dictionary
- Allows the user to:
  - Add a new student
  - Update an existing student’s grades
  - Remove a student
  - Search for a student and view their grades + average
  - View all grades for a specific subject

###KEY CONCEPTS USED
- Dictionaries
- Nested dictionaries
- Dictionary methods (`in`, `del`, `.items()`, `.values()`)
- Functions
- Menu-driven program using a `while` loop
